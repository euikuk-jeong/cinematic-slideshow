# Cinematic Slideshow

기기 갤러리의 사진 앨범(폴더)을 선택해 Ken Burns 효과(줌·팬)와 전환 효과를 적용한 슬라이드쇼로 감상하는 **로컬 전용** 모바일 앱입니다. 서버/클라우드 연동 없이 기기 안에서만 동작합니다.

> 핵심 화면(앨범 목록 → 앨범별 설정 → 슬라이드쇼 재생)이 모두 갖춰진 상태입니다. 슬라이드쇼 재생 화면은 Ken Burns·전환 효과까지 구현되었고, 터치 컨트롤·Keep Awake·배경음악 재생 연동이 남아 있습니다.

## 주요 기능

- 기기 앨범(폴더) 선택 후 슬라이드쇼 재생 — 앨범 검색·정렬, 특정 폴더 숨기기, 앨범 안 개별 사진 선택 지원
- Ken Burns 효과(줌·팬, 8방향 무작위) + 전환 효과(fade/slide/zoom/flip 등 9종 무작위)
- 배경음악 — 기기 음악 파일(다중 선택 + 순서 지정) 또는 앱 번들 기본 음원(5개 무드, 무드당 2곡 총 10곡)
- 재생 설정 — 전환 간격, 순서(순차/랜덤), 정렬 기준(촬영시간/파일명), 반복 여부
- 다크/라이트/시스템 테마

## 기술 스택

- React Native (Expo)
- 로컬 DB: `expo-sqlite`
- 미디어 접근: `expo-media-library`
- 블러 레이어: `expo-blur`
- iOS 빌드: EAS Build (클라우드)

## 상태

- Android 우선 개발(EAS dev client로 실기기 검증), iOS는 추후 확장 예정
- 수익 모델: 배너 광고(AdMob) 자리 예약 완료, 실제 SDK 연동은 다음 단계 — 슬라이드쇼 재생 화면에는 광고 미노출
- 진행 상황은 `doc/requirements.md`의 개발 마일스톤 절 참고(로컬 전용 문서)
