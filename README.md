# Cinematic Slideshow

기기 갤러리의 사진 앨범(폴더)을 선택해 Ken Burns 효과(줌·팬)와 전환 효과를 적용한 슬라이드쇼로 감상하는 **로컬 전용** 모바일 앱입니다. 서버/클라우드 연동 없이 기기 안에서만 동작합니다.

> 개발 초기 단계입니다. Expo 프로젝트 스캐폴딩만 완료된 상태입니다.

## 주요 기능 (MVP 범위)

- 기기 앨범(폴더) 선택 후 슬라이드쇼 재생
- Ken Burns 효과(줌·팬) + 전환 효과(페이드 등)
- 배경음악 — 기기 음악 파일 선택 또는 앱 번들 기본 음원(5개 무드, 무드당 2곡 총 10곡)
- 재생 설정 — 전환 간격, 순서(순차/랜덤), 반복 여부

## 기술 스택

- React Native (Expo)
- 로컬 DB: `expo-sqlite`
- 미디어 접근: `expo-media-library`
- iOS 빌드: EAS Build (클라우드)

## 상태

- Android 우선 개발, iOS는 추후 확장 예정
- 수익 모델: 배너 광고(AdMob), 슬라이드쇼 재생 화면에는 광고 미노출
